# IIG Digest — HARD RULE: сторінки 4–5 не залежать від IIG MARKET

**Затверджено:** 2026-11-11  
**Статус:** обов'язковий протокол формування HTML/PDF-дайджесту та Digest Builder.  
**Сфера дії:** IIG Platform / Robot #6 / ADMIN_2 / Preview / Approval / Publication.  
**Пріоритет:** це правило доповнює попередні вимоги щодо Marketplace, не скасовуючи ручне редакційне керування.

## 1. Головний принцип

**Сторінки 4–5 є необов'язковими додатковими сторінками, а не обов'язковими сторінками Marketplace.**

Їх можна формувати **незалежно від того, чи є позиції обладнання в IIG MARKET**. Відсутність Marketplace-контенту не блокує створення, попередній перегляд, погодження, HTML/PDF-генерацію чи публікацію дайджесту.

## 2. Дозволені типи матеріалів

1. **IIG ORIGINAL** — додаткові авторські статті, аналітика та редакційні матеріали IIG.
2. **PARTNER** — статті, технічні огляди та інформаційні матеріали партнерів.
3. **SPONSORED** — рекламні або спонсорські матеріали партнерів з помітним відповідним маркуванням.
4. **MARKETPLACE** — вибрані позиції обладнання з IIG MARKET із прямими посиланнями на їхні картки на `https://iig-eu.com/`.

На одній сторінці дозволено комбінувати всі зазначені типи. Наявність або відсутність одного типу не є умовою для використання інших.

## 3. Кількість сторінок

- **3 сторінки:** базовий дайджест без додаткових матеріалів; це коректний завершений випуск.
- **4 сторінки:** є матеріали для однієї додаткової сторінки.
- **5 сторінок:** є матеріали для двох додаткових сторінок.
- Порожні сторінки 4–5 не створювати. Не додавати вигадані матеріали чи обладнання для заповнення сторінок.
- Затверджені сторінки 1–3, зокрема титульна обкладинка, не змінюються автоматично через відсутність Marketplace.

## 4. Повноваження ADMIN_2 та ручне редагування

- ADMIN_2 визначає фінальний склад, порядок, розташування та тип кожного матеріалу на сторінках 4–5.
- Автоімпорт позначеного обладнання з IIG MARKET — лише **первинна збірка**, не остаточна редакція.
- Для кожної позиції зберігаються дії: **↑** вище, **↓** нижче, **⇄/↔** перенесення до іншого доступного блоку/позиції та **×** виключення з поточного випуску **без видалення картки** з IIG MARKET.
- Ручний порядок і виключення зберігаються **в межах конкретного випуску** та не скидаються під час Preview, HTML/PDF-render або звичайного повторного відкриття конструктора.
- Повторний автоімпорт не має самовільно повертати вилучені позиції або змінювати затверджений ADMIN_2 порядок.

## 5. Посилання, маркування, контроль якості

- Для MARKETPLACE: пряма клікабельна URL-адреса відповідної картки обладнання на `https://iig-eu.com/`.
- Для IIG ORIGINAL / PARTNER: клікабельне посилання на повний матеріал, якщо його передбачено.
- Для SPONSORED: явне маркування рекламного/спонсорського контенту; не видавати його за незалежну редакційну новину.
- Усі посилання перевіряти в HTML Preview і в кінцевому PDF, коли PDF формується.
- Українська мова — основна; англійська — за наявності відповідної версії / за встановленою логікою fallback.
- Публікація має проходити наявні редакційні та безпекові перевірки; відсутність Marketplace сама по собі не може бути причиною відмови.

## 6. Обов'язкові перевірки (acceptance criteria)

1. Порожній IIG MARKET + немає додаткових матеріалів → **3 сторінки**, без блокування випуску.
2. Порожній IIG MARKET + один PARTNER / SPONSORED / IIG ORIGINAL матеріал → **4 сторінки**, з відповідним типом і посиланням.
3. Порожній IIG MARKET + достатньо додаткових матеріалів для двох сторінок → **5 сторінок**.
4. Змішані MARKETPLACE + PARTNER + SPONSORED → усі типи дозволені на сторінках 4–5.
5. Ручне переміщення та виключення ADMIN_2 → зберігаються після Preview та HTML/PDF-render.
6. Повторний автоімпорт → не відновлює виключені позиції та не порушує ручний порядок.
7. Перевірка CTA, прямих посилань і маркування реклами → успішна.
